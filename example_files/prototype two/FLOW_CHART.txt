Prototype Two Flow (ASCII)

Root: example_files/prototype two
Outputs: data/outputs (via paths.outputs_root in config.json)

+------------------+            read by            +-------------------------------+
| config.json      | <-----------------------------| common.ConfigManager          |
+------------------+                               | - loads/merges sections       |

                                                   | - normalizes defaults         |
                                                   +-------------------------------+
                                                             |

                                                    |    checkpoints)               |
                                                    +-------------------------------+

Legend
- Solid arrows: function calls/import usage at runtime.
- "reads" arrows: JSON config files read by tools.
- "torch.save" arrows: checkpoints saved under data/outputs/checkpoints/.

Notes
- All paths are resolved via common.PathResolver; outputs_root controls where artifacts land.
- All entry points accept --config and default to example_files/prototype two/config.json.
