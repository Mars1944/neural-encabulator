Prototype Two Flow (ASCII)

Root: example_files/prototype two
Outputs: data/outputs (via paths.outputs_root in config.json)

Overall pipeline flow (how blocks connect)

config.json --> common.ConfigManager --> PathResolver
    |                                \
    |                                 -> ensure_outputs_ready/setup_folders (shared dirs)
    v
ModelManager (builds cnn_model.SimpleCNN/MultiTaskCNN) --> Trainer.fit
    |                                                               \
    |                                                                -> checkpoints/history under outputs_root
    v
InferenceRunner (infer.py) reads checkpoints + config --> produces heatmaps/NPY/stats
    |
    v
reports.py (confusion matrices/summary CSVs) and optional heatmap_viewer.py stitching

CNN core (model + optimization)

+-----------------------+    used by    +----------------------+    used by    +--------------------+
| cnn_model.py          | <-----------  | trainer.py           | -----------> | cnn_optim.py       |
| - SimpleCNN/MultiTask |               | - builds model       |              | - CnnOptim.build() |
| - ConvBlock           |               | - channels_last/AMP  |              |   -> optimizer,    |
| - count_parameters    |               |                      |              |      scheduler     |
+-----------------------+               +----------------------+              +--------------------+

Support code (config, paths, data)

+------------------+    read by    +-------------------------------+
| config.json      | <-----------  | common.ConfigManager          |
+------------------+               | - merges sections, seeds      |
                                   | - selects device              |
                                   | - ensure_outputs_ready hook   |
                                   +-------------------------------+
                                              |
                                              v
                                   +-------------------------------+
                                   | common.PathResolver           |
                                   | - anchors relative paths      |
                                   | - derives outputs_root dirs   |
                                   +-------------------------------+
                                              |
                                              v
                                   +-------------------------------+
                                   | vector_field_data.py /        |
                                   | data_loader.py                |
                                   | - load tiles or images        |
                                   | - dataset/label helpers       |
                                   +-------------------------------+

Training/validation loop

   CLI                builds model + config           trains/validates/checkpoints
+--------+    +-------------------------------+    +-------------------------------+
|train.py| -> | main.py + ModelManager        | -> | trainer.Trainer.fit           |
+--------+    +-------------------------------+    | - dataloaders (image/multitask|
                                                   |   with optional val split)    |
                                                   | - loss: CrossEntropy +        |
                                                   |   optional regression (MSE)   |
                                                   | - AMP + GradScaler optional   |
                                                   | - best/final torch.save       |
                                                   | - history CSV + plot          |
                                                   +-------------------------------+
                                                                |
                                                                v
                                                   data/outputs/checkpoints/model-*.pth

Inference + reports (postprocessing)

+---------+    +----------------------------+    tiles/probs/logits    +----------------------------+
| infer.py| -> | InferenceRunner            | ----------------------> | data/outputs/heatmaps/*.png|
+---------+    | - loads weights + config   |                         | data/outputs/stitched*.png |
               | - resolves channels        |                         | data/outputs/*.npy         |
               | - image inference loop     |                         +----------------------------+
               +-------------+--------------+
                             |
                             v
                     +----------------------+
                     | reports.py           |
                     | - confusion matrices |
                     | - summary CSVs/plots |
                     +----------------------+

Heatmap viewer (optional)

+------------------+    reads    +-----------------------------+
| config.json      | <---------  | heatmap_viewer.py           |
+------------------+             | - stitch/visualize outputs  |
                                 +-----------------------------+

Legend
- Solid arrows: runtime function calls/import usage.
- "reads" arrows: JSON config files read by tools.
- "torch.save" arrows: checkpoints saved under data/outputs/checkpoints/.

Notes
- All paths resolved via common.PathResolver; outputs_root controls artifact location.
- Entry points accept --config and default to example_files/prototype two/config.json.
